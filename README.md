# ProyectoFinalEstructuras de datos y algortimos 

Jorge Andrés Torres Vanegas y María Camila Vásquez Del Río

***Nota importante: El trabajo realizado tuvo como base un proyecto final de una curso anterior (paradigmas de programación) el trabajo se hizo en C#, sin embargo, como el requisito era hacer el backend en Java se hizo uso de inteligencia artificial (IA) para que nos ayudara a traducir el proyecto de un lenguaje a otro en ciertas partes del proyecto (las conexiones a la base de datos) ya que fue bastante complicado realizar la configuración. Adicionalmente nos apoyamos con la IA para la realización del frontend ya que al ser nuestra primera vez programando uno el resultado no fue el mejor y para presentar un trabajo agradable le pedimos nos ayudara tanto en como mejorarlo y como conectarlo con el backend.***

En el video se podra observar que el proyecto cumple con todas las funcionalidades establecidas en la Fase 1.

El proyecto incorpora tres (3) estructuras de datos. La primera es una bolsa que sirve para guardar los repuestos que se usan en el taller para la reparación de los vehiculos esta cumple la funcion de trabajar como el inventario del taller. La segunda estructura es una cola, al iniciar una reparación en el programa solicita especificar si entra por mantenimiento o por accidentalidad, en caso de escoger la primera opcion se guardan los vehiculos en la cola para ir atendiendo poco a poco. La ultima estructura de datos utilizada es la cola de prioridad que atiende a los vehiculos ingresados segun el nivel de gravedad. Los ordenes de las ultimas dos estructuras se pueden visualizar en la opcion de orden de accidentes. Finalmente se realizan logs de tiempo en el clienteRepositorio y filtroTiempoApi el primero para ver cuanto tardaba en conectar el proyecto con los clientes en la base de datos y el segundo para ver el tiempo que se demoraba en conectar todo el proyecto y en la carpeta util en el performaceReporter usamos logs OSHI y JOL.

El uso de IA no esta documentado en el codigo pero se explica en este apartado. Como se explico inicialmente nos apoyamos de IA para traducir de un lenguaje a otro, el proyecto inicial era demasiado grande y para realizar por ejemplo la conexion con la base de datos era un poco complicada asi que nos apoyamos con la IA para que nos indicara puntualmente que debiamos cambiar y que debiamos mejorar, asi mismo usamos la IA para que nos apoyara en la realizacion del frontend ya que como indicamos al comienzo era nuestro primer frontend y no entendiamos mucho la dinamica de como programarlo y como conectarlo con el backend asi que fue un gran apoyo ya que lo que hicimos fue pasarle nuestro codigo y la IA lo perfecciono y nos oriento en como hacer mejor la conexion.
